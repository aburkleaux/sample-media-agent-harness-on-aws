# Working with files and results

## Providing files

- **Attach** a file to your message (drag-and-drop or the attach control), then
  ask what to do with it: "read this", "analyze this video", "clean up this CSV".
- You can refer to an attached file naturally — "the spreadsheet", "the second
  image" — in the same conversation.

## What you can do with files

- **Read / summarize** — pull out the content or the key points.
- **Analyze** — extract findings, detect things, measure, classify.
- **Transform** — convert formats, edit, restructure, redact.
- **Create** — generate a new document, image, dataset, or media file.
- **Preview** — see images, video, audio, tables, and documents inline.
- **Download** — save any generated result.

You don't name file operations yourself — just say what you want done.

## Getting your results

- **Inline first.** Results show up in the conversation as they're produced:
  images and media play inline, tables and documents render, and there's a way
  to download each one.
- **Downloads.** Use the download control on a result to save it.
- **Later.** For background work, the result is retrievable after the job
  finishes — ask for it or open the job (see `jobs.md`).

## If a result seems missing

- Give background work a moment to finish, then ask for the result again.
- If it still isn't there, ask "what happened to my result?" — see
  `troubleshooting.md`.
