# Getting started

This assistant helps you get real work done through conversation. You describe a
goal; it does the work, shows results inline, and keeps track of longer tasks.

## The basics

- **Just ask.** Describe what you want in plain language. You don't need to know
  any commands or tool names.
- **Attach files** when your task needs them (a video to analyze, a spreadsheet
  to transform, a document to read). Drag-and-drop or use the attach control.
- **Results appear in the conversation** — text, images, media, tables, or
  documents — and you can download them.
- **Longer tasks keep running.** Some work runs in the background as a job; you
  can check on it and collect the result later (see jobs).

## A good first request

Pick something concrete, for example:
- "Summarize the attached PDF and list the action items."
- "Analyze this video for content flags and give me a timestamped report."
- "Turn this data into a chart and let me download it."

## What can it do here?

Ask "what can you do?" or "what's available?" and you'll get an answer based on
what is actually enabled in this deployment — the built-in abilities plus any
Skills, Custom Agents, and connected tools available to you. Availability can
differ between environments, so the answer reflects your current one.

## Ways to extend it

When the built-ins aren't enough, there are a few ways to add capability —
Skills, Tool Collections, connectors, Custom Agents, and workflows. See
`skills.md`, `tool-collections-connectors-workflows.md`, and `custom-agents.md`
for what each is and when to choose it.
