Agent Studio — 4 UI directions

Four distinct visual + layout directions for the agent app, each rendered with the real regions (sessions, chat, renderer/timeline, jobs, config). Click any card to open the full mockup. Same content, four very different feels — pick a direction (or mix) and I'll build it out.

Nocturne
Dark · glass · neon

Developer-premium

Deep space-black with glassmorphic panels and one electric violet→cyan accent. Confident, focused, "pro tool." Think Linear / Vercel.

Layout: icon rail · sessions column · chat · right renderer. Slim ⌘K command bar.
Paper
Light · editorial · warm

Calm & readable

Warm ivory, ink text, serif headings, a terracotta accent, lots of whitespace. Reads like a beautiful document. Think Notion / Stripe docs.

Layout: quiet left nav · wide centered chat · renderer as a right slide-over drawer.
Studio
Dark · dense · media

Media workstation

The timeline is the hero — a full-width multi-track dock at the bottom like a video/audio editor. Highest information density; best if media work is the core. Think DaVinci / Ableton.

Layout: session tabs · chat + inspector · full-width timeline dock at bottom.
Aurora
Light · gradient · friendly

Soft & approachable

Floating rounded panels on a pastel aurora gradient, a vivid multi-stop accent, playful but clean. Think Raycast / Arc.

Layout: floating nav · chat card · contextual right panel (Renderer / Jobs / Config tabs).
